## 当前已实现

- 输入按项目、数据集和类型限定；普通文件使用数据库分页，结果文件不会挤占输入候选。数据集摘要使用数据库聚合；分析向导及摘要先选范围再取轻量候选，多份表格按类型搜索分页，完整克隆选择保留。
- 替换上传保留历史文件与版本，失败不退休原输入。被任务引用的版本不能删除或更改归属。共享物理路径的删除有生命周期保护。
- 文件上传和目录登记使用稳定操作 ID，重复及并发请求复用原保存结果；响应中断会核对保存状态，状态未确认时保留选择，不把文件名当作保存证据。明确重新选择仍可新建操作。
- 直接导入链接使用 URL 中指定的数据集。上传草稿及失败队列保留逐项状态，取消后续项、移除草稿和离开项目均有对应交互。
- 样本、文件、附件、分组、项目设置和顶部项目编辑都有未保存保护。保存失败保留字段；设置和顶部编辑保存后失效旧缓存，概览立即读取新内容。
- 分组方案从真实来源字段与取值选择，可调整顺序；替换来源、字段或手工模式将丢弃自定义选择时提示。方案绑定具体来源版本，复制/编辑保留其他属性；分析读取保存的方案快照。必要列和样本计数默认不携带完整样本数组。
- 登记导入/删除按来源资产和数据集处理，保留人工字段与来源不明旧记录，原始编号 `001` 保持文本。已有来源登记的登记表禁止普通归属修改，文件说明仍可编辑；未附来源的独立补录不会跟随其他文件移动。
- 样本登记列表支持逐项物种/疾病条件与自定义值，筛选、范围、页码在 URL 中保留。显示数据集、来源及人工维护字段。零结果仍显示项目上下文。
- 输入样本覆盖区分未提供输入、识别未完成、已识别文件不含编号。部分识别或失败来源不能作为“编号不存在”的证据；可选输入缺失不被当作分析错误。需处理筛选包含其他来源尚未确认的样本。
- 校验摘要和样本来源按资产 ID 打开对应文件详情，支持当前页以外的历史版本。同名文件不会只按名称定位；关闭与返回保留原筛选/页码。文件校验终态、重试和旧 PEP 报告提示复用已有实现。
- 工作台切换、侧栏、概览及分析中心任务快捷入口保持项目和数据集范围，显式“全部数据集”不会由会话偷偷替换。
- 项目卡片、详情和结果分页采用相同产物身份规则；SQL/Mongo 同一产物及 SQL 重复登记只计一次，同任务不同路径产物保持独立。无路径时不猜测记录相同。旧 Mongo 元数据中的分析类型可筛选。项目列表结果身份使用一批 SQL 和一批 Mongo 查询。
- 项目附件和结果按标签页加载；有限预览、目录子表分页、ZIP 授权下载、失败删除保留选择已实现。现有小屏紧凑导航、固定身份列继续保留。
