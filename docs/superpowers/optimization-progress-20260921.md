## 后续补充：权限扫描优化

使用 scandir 返回的文件属性，减少重复查询；不跳过后续新导入文件。读取目录失败会明确终止初始化，符号链接及特殊文件不修改。

Linux 容器内 20,000 个文件、101 个目录，三轮扫描中位耗时从 0.296 秒降为 0.111 秒，约减少 63%。测试使用合成临时目录和已正确设置的权限，不能直接外推服务器磁盘耗时。5 项权限回归通过，覆盖非 root 写入、新导入文件、外部符号链接、特殊文件及扫描错误。

可在容器内运行 docker/tests/benchmark_volume_permissions.py --baseline /path/to/previous_initializer.py 复测；基准只创建并删除自己的临时目录。

模块匹配规则核对发现部分模块使用内连接，另一些模块有自定义样本编号归一化。仍需按模块分别对齐，不能统一强制完全相同的样本集合。
