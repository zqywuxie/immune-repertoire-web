## 1. 总览：目录与分析主题

- `DB_260213/`：公共数据库（VDJdb/McPAS）比对与特异性比例统计，外加箱线图统计。
- `ML_260213/`：机器学习建模（预处理 + RandomForest 训练/交叉验证/ROC/特征重要性）。
- `MN_260213/`：MAIT/iNKT 相关限制性 CDR3 统计与可视化。

- `Pep_260213/`：核心肽段（CDR3(pep)）共享度、V/J/VJ usage、显著性热图、类别组合统计、CDR3 排布热图。

- `Pgen_260213/`：基于 SoNNia/Sonia 的受体生成概率（Pgen/Q/Ppost）评估。

- `Profile_260213/`：Profile 指标的分组差异箱线图分析。
- `TopClone_260213/`：TopN clone 占比统计与分组分析。
- `UMAP_260213/`：按显著特征集合自动做 UMAP 降维并输出坐标结果。
- `UMAPin_260213/`：将 usage 特征拼接后进行 UMAP 的交互式 Notebook 流程。

## 2. 运行环境与依赖

多数 `.py` 脚本为“直接执行型”（无 argparse），通过**修改脚本顶部变量**控制参数：

```bash
python 脚本名.py
```

Notebook 按单元顺序执行。

## 3.1 DB_260213：数据库比对与特异性比例

### 3.1.1 分析内容
1. 将样本 CDR3 与 `VDJdb` / `McPAS-TCR` 做精确匹配（当前仅 TRA/TRB）。
2. 输出每个样本每条链在两个数据库中的匹配明细。
3. 计算每个样本链在数据库命中的 copy 占比（specify ratio）。
4. 与 `Profile_All.csv` 的分组字段合并，生成可直接做统计图的数据。

### 3.1.2 输入
- `Profile_All.csv`
- `DB/vdjdb.csv`
- `DB/McPAS-TCR.csv`
- `artificial_peps/*.csv`

### 3.1.3 输出
- `alignment/*__VDJdb.csv`
- `alignment/*__McPASTCR.csv`
- `specify_ratio.csv`

### 3.1.4 脚本与参数

#### A) `Alignment.py`

**可控参数（脚本顶部）**

| 参数 | 默认值 | 作用 | 调整建议 |
|---|---:|---|---|
| `profile` | `"./Profile_All.csv"` | 临床分组信息文件路径 | 换数据批次时修改 |
| `categorys` | `["therapy","disease"]` | 合并到输出中的分组列 | 可扩展为更多分组列 |
| `contained_Pathology` | `False` | 是否按病原关键词过滤数据库匹配 | 做特定疾病亚分析时设 `True` |
| `use_Pathology` | `["Diabetes Type 1"]` | 病原过滤白名单 | 与上项联动 |

**核心逻辑**
- TRA 匹配 `McPAS` 的 `CDR3.alpha.aa`，TRB 匹配 `CDR3.beta.aa`。
- VDJdb 使用 `CDR3` 列匹配并统一字段名。
- 仅保留人类条目（McPAS: `Human`；VDJdb: `HomoSapiens`）。
- 返回 `(sample, chain, ratio_vdj, ratio_mcpas)` 并汇总。

**运行**
```bash
python Alignment.py
```

### 3.4.5 `5.Heat_map_Thread.py`

**分析目标**
- 对 `usage_cate` 中每个文件：
  1) 按分组做两两 Mann-Whitney U 检验；
  2) 根据 p 值和均值方向编码（±10, ±5, 0）；
  3) 绘制显著性方向热图；
  4) 导出对应编码矩阵 CSV。

**输入**
- `usage_cate/**/*.csv`

**输出**
- `heatmap/<原文件路径层级>/<category>.jpg`
- `heatmap/<...>/csv_file/<category>.csv`

**可控参数**

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `data_split_point_begin` | `1` | 分组列起始索引（含） |
| `data_split_point` | `2` | 分组列结束索引（不含） |
| `file_dir` | `"usage_cate"` | 输入目录 |
| `threash_hold_s` | `0.005` | 强显著阈值（决定 10/-10） |
| `threash_hold_p` | `0.05` | 显著阈值（决定是否记 0） |
| `remove_list` | `[0]` | 去除分组值 |
| `global_path` | `"heatmap"` | 输出根目录 |
| 并行核数 | `cpu_count()` | 文件级并行 |

## 3.8 UMAP_260213：按显著指标集合自动降维

### 3.8.1 分析内容
1. 在每个分组列内，对各特征做两两 Mann-Whitney U；
2. 取显著特征并构造多类别组合；
3. 对每个组合跑 UMAP；
4. 输出图 + 点坐标 CSV + meta 参数文本。

### 3.8.2 输入/输出
- 输入：`Datapoint/Profile_All.csv`
- 输出：
  - `umap_all/<文件名>/<category>/*.pdf`
  - `umap_all/csv_file/<文件名>/<category>/*_umap_points.csv`
  - `*_umap_meta.txt`

### 3.8.3 `Umap_12_08.py` 可控参数

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `file_dir` | `Datapoint` | 输入文件夹 |
| `filename_or_file` | `1` | 文件夹/单文件模式 |
| `threshold_pvalue` | `0.05` | 显著特征阈值 |
| `data_split_point_begin` | `therapy` | 分组列起始 |
| `data_split_point_over` | `disease` | 分组列结束（含） |
| `param_begin` | `TRA_percent_reads_all` | 指标起始列 |
| `param_over` | `IGHM_IGHD_VDJnuc_SHM1` | 指标结束列（含） |
| `remove_list` | `[0]` | 去除分组值 |
| `pair_or_mutiple` | `1` | 预留开关（当前流程以组合分析为主） |
| `umap_n_neighbors` | `6` | UMAP 邻居数 |
| `umap_min_dist` | `0.01` | UMAP 最小距离 |
| `n_epochs` | `50`（代码内） | UMAP 训练轮次 |
| `random_state` | `42`（UMAP） | 随机种子 |

**备注**
- 输出表里写入了 `umap_random_state=40`，与 UMAP 初始化的 `42` 不一致，若要严格可复现建议统一。

## 6. 常见问题与注意事项

1. **脚本大多无命令行参数**：通过修改顶部变量控制。
2. **列名硬编码较多**：换数据批次要先核对列名（尤其 `param_begin/over`、分组列名）。
3. **并行处理**：多个脚本默认 `cpu_count()` 全核，机器繁忙时可改小。
4. **空值与异常值**：很多脚本使用 `fillna(0)`，解释统计结果时要注意该处理影响。
5. **路径依赖当前工作目录**：建议在脚本所在目录下执行，避免相对路径失效。
