# Pipeline 参数配置说明

> 所有脚本均通过在**脚本顶部修改变量**来控制参数，无命令行参数接口。运行时直接 `python 脚本名.py`，Notebook 按单元顺序执行。

---

## 一、全局输入数据

在运行各模块前，需要准备以下通用数据：

| 数据 | 路径 | 说明 |
|---|---|---|
| 样本受体文件 | `artificial_peps/*.csv` | 每个样本-链一个 CSV，必备列：`CDR3(pep)`, `V`, `J`, `copy` |
| 分组信息文件 | `Profile_All.csv`（或 `Profile_All_therapy.csv`） | 必备列：`sample` + 分组列（如 `therapy`, `disease`） |
| 公共数据库 | `DB/vdjdb.csv`, `DB/McPAS-TCR.csv` | 仅 DB 模块使用 |

## 三、换数据批次时重点修改的参数

按优先级排序：

1. **输入数据路径**：几乎所有脚本的 `file_dir` / `datapoint_path` / 输入目录
2. **分组列名**：`data_split_point_begin/over`（Profile/UMAP/BoxPlot）、`Group`（Pep 3-4）、`categorys`（DB/TopClone）
3. **指标列范围**：`param_begin/over`（Profile/UMAP/BoxPlot），需确认 Profile_All.csv 中实际列名
4. **分组排序**：`index_sorted` / `list_sorted` / `categorys` / `arrange_dict`，需确认新数据的分组值
5. **链类型**：如果涉及不同链（如 BCR 的 IGK/IGL vs IGH），需检查脚本中硬编码的链类型列表
6. **物种**：Pgen 模块的 `Species` 参数

## 四、注意事项

- 脚本中大量硬编码列名（尤其是 `param_begin`/`param_over`），换数据后务必先检查 Profile_All.csv 中的实际列名
- 多数脚本依赖相对路径（`./pep_data`、`./artificial_peps` 等），建议在脚本所在目录下运行
- 并行脚本默认使用全部 CPU 核（`cpu_count()`），资源紧张时可手动改小
